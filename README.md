Descrição do Projeto
Este repositório contém dois exercícios de animação desenvolvidos em CSS3 e JavaScript:

1. **Carta 3D (`/animacao`):** Efeito de flip de carta interativo acionado por botões utilizando transformações 3D e manipulando classes no DOM via JS.
2. **Balão Subindo (`/balao`):** Animação contínua de subida de um balão pela tela utilizando CSS `@keyframes`.
